# iCloud Panel Portal

A responsive, single-file glass-themed interface demo.

## Run
Open `index.html` in any modern browser. No installation or build is required.

## Features
- Aimbot and Location preference switches
- Status notifications and clearable activity history
- Responsive layout and keyboard-accessible controls

The switches update the interface only. This demo does not modify games or access location. It is independent of Apple.

## Player lookup
Live Free Fire UID lookup is pending a verified, working API provider. No fabricated player names are returned.
